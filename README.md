# 本地 API 测试台

填入接口地址和 API Key，就能在本地查看模型列表、测试接口能否正常回复、对比不同模型的响应速度，还可以让多个文本模型同台画一道 SVG 动画题（比如“鹈鹕骑自行车”），在同一个窗口里直接对比生成效果。

本工具在自己的电脑上运行，提供图形界面（GUI）和命令行（CLI），适合需要检查模型接口可用性、管理多家供应商与多组 Key、横向对比模型表现的用户。

> **说明**：这是一个本地测试工具，不是聊天客户端，也不提供免费模型额度。点击获取模型或发起测试时，程序会向你填写的接口发送请求，可能会消耗对应接口的额度。

### 启动步骤

1. 下载 `API-Tester-Windows-x64-folder-portable.zip`。
2. **完整解压**压缩包，进入解压出的 `API-Tester` 文件夹。

- **请保留完整文件夹**：程序运行依赖同目录下的 `_internal` 文件夹，请勿只单独拷走 `API-Tester.exe`，也不要在压缩包里直接双击运行。
- **SVG 动画预览组件**：使用「鹈鹕测试」预览 SVG 动画时，系统需要具备 **Microsoft Edge WebView2 Runtime** 和 **.NET Framework 4.6.2 或更高版本**（Windows 11 通常已自带；若提示缺少 WebView2，可前往[微软官方页面下载安装](https://developer.microsoft.com/microsoft-edge/webview2/)）。

## 能做什么

### 1. 检查接口连通性与比较速度
- **模型获取与筛选**：一键拉取接口的模型列表，也支持手动输入模型 ID 添加、按关键词筛选或删除模型。
- **单模型连通性测试**：检查模型能否正常回复，直接查看失败原因、日志和原始响应内容。
- **流式测试**：开启流式后可边收边看正文输出，并记录等待第一段正文返回的时间。
- **多模型批量测速**：并发测试多个模型，完成后可将结果导出为 CSV 或 JSON 文件。
- **多协议支持**：支持 `Chat Completions`、`Anthropic Messages` 和 `Responses` 三种常用文本协议。

### 2. 管理多个供应商与多组 Key
- **供应商档案**：可以保存、切换、重命名和删除不同供应商的连接设置。
- **单供应商多 Key**：同一个供应商下可以保存多组命名 Key，方便区分不同账号或额度的 Key。
- **独立模型列表**：模型列表按「供应商 + 命名 Key」分别保存，切换 Key 时自动切换对应的模型列表；支持选择是否在关闭程序后记住模型列表。
- **便捷复制**：模型列表中的模型 ID 支持鼠标按住拖动选字复制，也可以右键直接复制完整 ID。

### 3. 比较模型画 SVG 动画的能力（鹈鹕测试）
- **同题对比文本模型**：默认题目是让文本模型生成“鹈鹕骑自行车”的 SVG/HTML 动画；也支持自定义 SVG 提示词，并可将常用提示词保存为命名快捷模板（支持选择、重命名和删除）。
- **单窗口集中预览**：最多同时运行 4 个生成请求，所有模型的生成结果都集中在主窗口同一个预览区内切换查看，不会弹出多个独立窗口。
- **查看作品与排错**：可以查看渲染后的动画、原始回复文本或失败原因；右键记录可定位本地文件、在系统浏览器中打开作品，或从列表中移除记录（“移除记录”仅从界面列表隐藏，本地原始文件仍会保留，也不会中止已发出的请求）。
- **请求互相隔离**：每次测试只向模型发送当前题目文本，不会把历史作品、其他模型的回复或本地目录文件发给模型。
- **测试性质说明**：这是针对**文本模型生成 SVG 代码能力**的测试，不调用 `/images/generations` 绘图接口；内置预览区主要支持 SVG/CSS 动画，出于安全限制，脚本执行与外部网络资源会被拦截。

### 4. 查看 t/s 速度统计
- **实时与汇总显示**：「t/s 速度」标签页集中汇总已完成测试的速度记录；在鹈鹕测试生成过程中，左侧记录卡片和右侧详情区也会直接显示耗时、当前状态（等待 / 思考 / 输出）和实时速度。
- **计算方式说明**：生成过程中若接口尚未返回准确 token 用量，会显示带 `≈` 的估算值；请求完成后的平均速度按 **“接口报告的输出 token ÷ 请求总耗时”** 计算（**包含网络与首字等待时间**，并非纯解码速度）。若接口未返回 token 用量则显示“未报告”；服务端未返回给程序的隐藏思考内容无法计入。

## 第一次怎么用

1. **填地址和 Key**：在左上角「连接」区域填入 `Base URL`（接口地址）和 `API Key`。（如果上方设置区被收起了，点击右上角的 **「展开设置」** 即可显示。）
2. **准备模型**：点击 **「获取模型」** 拉取列表，或者在手动输入框填入模型 ID 后点 **「添加模型」**。
3. **开始测试**：
   - 测单个模型：在列表中选中模型，点击 **「测试连通性」**（或双击模型）。
   - 测多个模型：选中多个模型后，点击 **「批量测速」**。
4. **体验鹈鹕测试（SVG 动画对比）**：
   - 在左侧列表选中一个或多个模型，点击 **「鹈鹕测试」** 按钮——注意此时**只是打开预览页面**，还不会发送请求。
   - 在鹈鹕测试页面确认题目和参数后，点击页面内的 **「开始生成」**，程序才会正式请求模型。

## 配置文件、作品保存与更新方法

- **配置文件位置**：你保存的供应商设置、模板和 API Key 存储在程序同目录的 `settings.json` 中。**注意：`settings.json` 中的 API Key 为明文保存，截图或把文件夹发给别人前请先移除该文件。**
- **作品保存位置**：SVG 动画测试的提示词、模型原始回复、HTML 作品和运行记录保存在程序同目录的 `pelican/results/` 下。
- **如何更新或搬家**：
  - 备份或移动位置时，请直接移动整个 `API-Tester` 文件夹。
  - 更新版本时，将新版绿色包解压到一个新文件夹，再把旧文件夹里的 `settings.json` 和 `pelican/results/` 复制到新文件夹即可继承全部配置和历史作品。
- **什么时候会消耗接口额度**：只有点击「获取模型」、「测试连通性」、「批量测速」、「Embedding」或鹈鹕页面里的「开始生成」时才会访问接口；平时浏览历史作品、查看「t/s 速度」页或增删提示词模板，都不会发起网络请求。

### 进阶测试与请求配置

- **Embedding 测试**：在图形界面中选中向量模型，点击「Embedding」测试并查看返回的向量维度。
- **视觉入参检查（`--image`）**：请求时附带一张内置的 `1×1` PNG 测试图，仅用于检查接口是否接受图片入参格式，不是完整的视觉理解能力评测。
- **图片生成接口检查（`--image-gen`）**：命令行下请求 `POST /images/generations` 检查绘图接口可用性（与鹈鹕 SVG 代码测试相互独立）。
- **网络与请求头定制**：支持配置 HTTP 代理、跳过 TLS 证书校验（`--insecure`）、切换鉴权头模式（`auto` / `bearer` / `x-api-key` / `both`）以及追加自定义请求头。
- **客户端请求头模拟（Profile）**：
  - 支持 `default`、`claude-code`、`codex`、`pi` 四种预设，模拟对应客户端的请求头并切换相应协议（例如 `claude-code` 走 Anthropic Messages，`codex` 走 Responses）。
  - 会话 ID 机制：每创建一个 `ApiClient` 实例会自动生成一个随机 UUID v4，同一实例内的请求复用该 ID（`claude-code` 写入 `X-Claude-Code-Session-Id`，`codex` 写入 `session_id`，可通过自定义请求头覆盖；鹈鹕多模型测试默认为每个模型创建独立实例）。
  - **注意**：这只是请求头与协议层面的模拟，不代表能接续客户端已有的真实会话，也不保证服务端一定会将请求识别为官方客户端。

### 命令行（CLI）用法示例

以下命令适用于源码版：先安装 Python，再在克隆或下载的源码目录中运行。Windows 绿色包不包含 `api_tester.py`，使用绿色版时按前面的步骤双击启动即可。

```powershell
# 测试单个模型的流式连通性
python api_tester.py --base-url https://api.example.com/v1 --api-key API_KEY --skip-models --test-model MODEL_ID --stream

# 查看全部命令行参数说明
python api_tester.py --help
```

（源码版也可使用 `run.bat` / `.\run.ps1` 透传上述参数；这两个脚本不包含在 Windows 绿色包中。）
